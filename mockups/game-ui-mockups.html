Wins

  • A Slim top strip — back ←, room code, mode chips, and overflow ⋯ for invite-link / conn-state / draw-offer / settings. Site brand and 7-item nav are hidden inside the game view.
  • B Board stays in its natural 8×4 orientation — same aspect ratio as today, but stripping the chrome above lets the board sit ~1/3 down the screen instead of ~1/2. Coordinate labels (a–h) added under the board to match transcript notation.
  • C Per-player cards flank the board — opponent above, you below. Each card carries avatar, name, ELO, color cue, clock, and a captured-pieces tray (with a +N material differential). The active player's card glows in accent and shows "· move" — replaces both the turn pill and the entire piece-counts block.
  • D Transcript dominates the lower half — what was today a cramped 280 px max-height list below the board (with the bottom action row buried below it) becomes the main vertical content, easily showing 7+ moves at a glance, with playback controls (⏮ ◀ LIVE ▶) docked at the bottom.
  • E Thumb-reach action bar pinned with env(safe-area-inset-bottom): undo (replay step), offer-draw, resign. Rematch / Analyze / Back take over after game end.
  • The freed vertical space (was: 7-row sticky meta header) now belongs to the transcript and player cards — both of which actually help during play.

Wins

  • 12 Per-player cards — avatar, name, ELO, color, clock, and a real captured-pieces tray (faded glyphs) directly under each player. Active player's card glows. Replaces the entire piece-counts block.
  • 13 Board grows to fill the middle column — three-column layout sizes board to min(viewport − sidebars, container), so a 1440-px display gets a ~720–800 px board. Page cap removed for the game view only. File labels (a–h) under the board match transcript notation.

  • In-game top strip replaces the marketing header + 7-item nav with a one-row breadcrumb (back ←, room code, mode, copy, ⋯).

Notes on the mockups

  • The portrait "rotate the board, not the user" approach (4×8 grid) is the biggest behavioral change. An alternative is a CSS transform: rotate(90deg) applied only to the board container — that preserves the existing 8×4 grid rendering but reads as portrait. Either works; rotating the grid in CSS layout is cleaner because hit-testing and coordinates stay native.
  • The active-player glow + per-side material tray makes the explicit "Your turn" pill redundant in most states. Keep the pill for accessibility/screen-reader text and an animated affordance the first few moves; consider hiding it after the user has made a move or two.
  • Coordinate labels (a–h under the board, 1–4 along one side) are essential for desktop where notation is visible in the transcript, but they can be optional on mobile to save vertical space.
  • "Immersive landscape" — when entering landscape on iPhone, auto-hide the site header and nav, expand board to fill the viewport short axis. The user's last orientation can be remembered across sessions.
  • The proposed bottom action bar on portrait is the right place for context-sensitive actions: Offer draw / Resign during play, Rematch / Analyze / Back to lobby after game end.
